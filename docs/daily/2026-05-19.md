## 一、通用 Outputs 聚合机制（Universal Outputs Aggregation）

**目标：** 替换 `SupervisorState` 中固定的结果字段（`code_change_report`、`review_results`），改用通用 `outputs: dict`，让 Worker 产出动态聚合、Synthesize 动态渲染。

| 提交 | 改动点 |
|---|---|
| `e04ea80` | `SupervisorState` 新增 `outputs: Annotated[dict, operator.or_]`；`PlanStep` 新增 `output_key: str` |
| `13a77e8` | `_resolve_input` 支持 `${outputs.xxx}` 引用语法 |
| `2fb5ed6` | `code_analyzer_wrapper` 改为写入 `outputs[output_key]` |
| `0e7d566` | `case_reviewer_wrapper` 和 `synthesize_node` 迁移到 `outputs` |
| `5056969` | 更新 `planner.md`、`synthesize.md` Prompt 模板；修复集成测试 Mock |
| `580ba30` | 移除废弃的 `code_change_report` 和 `review_results` 字段 |

**效果：**
- Worker 不再硬编码字段名，每个 `PlanStep` 声明自己的 `output_key`
- 多模块分析时，同 `output_key` 的结果自动拼接
- `synthesize_node` 遍历 `outputs` 字典动态生成 Prompt，无需关心具体字段
